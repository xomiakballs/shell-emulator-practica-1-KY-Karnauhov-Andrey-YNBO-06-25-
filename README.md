# Эмулятор языка оболочки ОС (Вариант №9)

## Общее описание

GUI-эмулятор командной строки UNIX-подобной ОС на Python 3 + Tkinter.
Окно состоит из области вывода и строки ввода, в заголовке окна
указано имя VFS (`vfs-9variant`). Введённая строка разбивается
по пробелам на команду и аргументы.

Статус: **Этап 1 — REPL**. Команды `ls` и `cd` пока заглушки.

## Функции и настройки

- Неизвестная команда или неверные аргументы не роняют программу:
  в окне выводится сообщение, начинающееся со слова «Ошибка».
- `exit` — закрывает эмулятор (с аргументами — ошибка).
- `ls [путь]`, `cd [путь]` — заглушки: печатают своё имя и аргументы.
  Больше одного аргумента — ошибка.

## Сборка и запуск

Сборка не нужна: требуется только Python 3 (Tkinter входит в стандартную
поставку). Запуск из корня репозитория:

```
run.bat
python src/main.py
```

## Тесты

Этап 1 проверяется вручную в интерактивном режиме: список команд
и ожидаемых ответов — в `tests/stage1_manual.txt`.

## Примеры использования

```
vfs-9variant$ ls /home
ls: вызвана с аргументами: ['/home']
vfs-9variant$ cd a b
Ошибка: cd: слишком много аргументов
vfs-9variant$ foobar
Ошибка: неизвестная команда foobar
vfs-9variant$ exit
Выход из эмулятора...
```
