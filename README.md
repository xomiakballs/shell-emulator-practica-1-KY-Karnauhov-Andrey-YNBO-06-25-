# Эмулятор командной строки (Вариант №9)

## 1. Общее описание

Программа — это окно, похожее на командную строку Linux.
В нём можно вводить команды (`ls`, `cd`, `wc` и другие), а программа
отвечает так же, как настоящая командная строка.

Работает с **виртуальной файловой системой (VFS)** — это «ненастоящие»
папки и файлы, которые читаются из CSV-файла и хранятся только
в памяти программы. Настоящие файлы на компьютере не меняются.

- Язык: Python 3, окно сделано на Tkinter.
- В заголовке окна написано имя VFS: `vfs-9variant`.
- Работа выполнена в 5 этапов, каждый этап — отдельный коммит.

## 2. Функции и настройки

### Команды

| Команда | Что делает |
|---|---|
| `ls [папка]` | показывает, что лежит в текущей или указанной папке |
| `cd [папка]` | переходит в папку; `cd ..` — на уровень выше, `cd` — в корень |
| `who` | показывает имя пользователя компьютера |
| `wc <файл>` | считает строки, слова и символы в файле |
| `tac <файл>` | выводит строки файла задом наперёд |
| `chown <владелец> <путь>` | меняет владельца файла или папки |
| `vfs-save <файл>` | сохраняет текущую VFS в CSV-файл |
| `exit` | закрывает программу |

Если команда неизвестна или у неё неправильные аргументы, программа
не ломается, а пишет сообщение, которое начинается со слова «Ошибка».

### Параметры запуска

- `--vfs <путь>` — какой CSV-файл с VFS загрузить.
- `--script <путь>` — какой стартовый скрипт выполнить.

При запуске программа выводит значения этих параметров
(строки с пометкой `[отладка]`).

### Стартовый скрипт

Обычный текстовый файл: одна команда на строку. Строки, которые
начинаются с `#`, — комментарии, они пропускаются. Во время выполнения
в окне видно и команду, и ответ на неё. Если в строке ошибка,
программа пишет её номер.

### Формат VFS (CSV-файл)

```
type,path,encoding,content,owner
dir,home,,,root
file,home/note.txt,text,Привет,root
file,bin/data.bin,base64,0J/RgNC4,root
```

- `type` — `dir` (папка) или `file` (файл);
- `path` — путь, вложенные папки через `/`;
- `encoding` — `text` (обычный текст) или `base64` (двоичные данные);
- `content` — содержимое файла;
- `owner` — владелец (если нет, считается `root`).

Если файла VFS нет или в нём неправильные строки, программа
сообщает об ошибке.

## 3. Как запустить и как запустить тесты

Нужен только Python 3. Ничего собирать не нужно.

Запуск программы — двойной щелчок по `run.bat` или команда в консоли:

```
python src/main.py --vfs tests/vfsdeep.csv --script tests/startall5.txt
```

Тесты — это `.bat`-файлы в папке `tests`, запускаются двойным щелчком:

| Файл | Что проверяет |
|---|---|
| `test1` … `test7` | параметры запуска и стартовый скрипт (Этап 2) |
| `test8_vfs_min.bat` | VFS из одного файла |
| `test9_vfs_several.bat` | VFS из нескольких файлов |
| `test10_vfs_deep.bat` | VFS с 3 уровнями папок |
| `test11_vfs_missing.bat` | файла VFS нет — ошибка |
| `test12_vfs_bad.bat` | неправильные строки в VFS — ошибки |
| `teststage3.bat` | все команды Этапа 3 |
| `teststage4.bat` | `ls`, `cd`, `who`, `wc`, `tac` |
| `teststage5.bat` | `chown` |

Этап 1 проверяется вручную: команды для ввода — в `tests/stage1_manual.txt`.

## 4. Примеры использования

```
vfs-9variant$ ls
bin home
vfs-9variant$ cd home/user/docs
cd: текущая папка /home/user/docs
vfs-9variant$ wc note.txt
3 6 41 note.txt
vfs-9variant$ tac note.txt
третья строка
вторая строка
первая строка
vfs-9variant$ chown ivan note.txt
chown: владелец /home/user/docs/note.txt теперь ivan
vfs-9variant$ cd nofolder
Ошибка: cd: нет такой папки: nofolder
vfs-9variant$ exit
Выход из эмулятора...
```
