# Эмулятор языка оболочки ОС (Вариант №9)

## Общее описание

GUI-эмулятор командной строки UNIX-подобной ОС на Python 3 + Tkinter.
Окно состоит из области вывода и строки ввода, в заголовке окна
указано имя VFS (`vfs-9variant`). Введённая строка разбивается
по пробелам на команду и аргументы.

Статус: **Этап 2 — Конфигурация**. Команды `ls` и `cd` пока заглушки.

## Функции и настройки

- Неизвестная команда или неверные аргументы не роняют программу:
  в окне выводится сообщение, начинающееся со слова «Ошибка».
- `exit` — закрывает эмулятор (с аргументами — ошибка).
- `ls [путь]`, `cd [путь]` — заглушки: печатают своё имя и аргументы.
  Больше одного аргумента — ошибка.
- Параметры командной строки:
    - `--vfs <путь>` — путь к CSV-файлу с VFS;
    - `--script <путь>` — путь к стартовому скрипту.
- При запуске выводятся значения всех параметров (строки `[отладка]`).
  Неизвестный параметр или параметр без значения — сообщение об ошибке.
- Стартовый скрипт — текстовый файл UTF-8, одна команда в строке.
  Строки, начинающиеся с `#`, и пустые строки пропускаются (комментарии).
  На экране видны и ввод (`vfs-9variant$ команда`), и вывод, как при
  ручном диалоге. При ошибке выводится номер строки скрипта; `exit`
  в скрипте завершает его выполнение.

## Сборка и запуск

Сборка не нужна: требуется только Python 3 (Tkinter входит в стандартную
поставку). Запуск из корня репозитория:

```
run.bat
python src/main.py --vfs myvfs.csv --script tests/start.txt
```

`run.bat` передаёт параметры дальше, например
`run.bat --vfs tests\vfsdeep.csv`.

## Тесты

Скрипты Windows в папке `tests` (запуск двойным щелчком). Каждый
запускает эмулятор из корня репозитория с нужными параметрами.
Ручная проверка Этапа 1 — `tests/stage1_manual.txt`.

| Скрипт | Что проверяет |
|---|---|
| `tests/test1_no_params.bat` | запуск без параметров |
| `tests/test2_vfs_only.bat` | только `--vfs` |
| `tests/test3_script_only.bat` | только `--script` |
| `tests/test4_both_params.bat` | оба параметра |
| `tests/test5_script_exit.bat` | `exit` внутри скрипта |
| `tests/test6_missing_script.bat` | несуществующий скрипт (ошибка) |
| `tests/test7_bad_params.bat` | неизвестный параметр и параметр без значения (ошибки) |

## Примеры использования

```
> python src/main.py --vfs myvfs.csv --script tests/start.txt
[отладка] --vfs: myvfs.csv
[отладка] --script: tests/start.txt
vfs-9variant$ ls /home
ls: вызвана с аргументами: ['/home']
vfs-9variant$ foobar 1 2
Ошибка: неизвестная команда foobar
Ошибка в строке 9 стартового скрипта
```
